About the Project

An end-to-end data engineering workflow that extracts a public Twitter dataset, transforms it with Pandas, validates data quality, and produces a refined dataset.

Apache Airflow orchestrates the ETL workflow locally, while the static dataset keeps the project reproducible and free from paid API dependencies.

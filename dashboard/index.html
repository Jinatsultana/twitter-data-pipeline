About the Project

This project demonstrates an end-to-end data engineering workflow. A publicly available Twitter dataset is extracted from CSV, transformed using Pandas, validated using data quality checks, and loaded into a refined output dataset.

Apache Airflow is used to orchestrate the ETL workflow locally. The original reference project used the Twitter API, while this implementation uses a static dataset to keep the pipeline reproducible and independent of paid API access.
